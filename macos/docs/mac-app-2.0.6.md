# Workspace OS 2.0.6 · Mac 单入口

双击「Workspace OS」即可使用 NEXUS，无需打开终端或另开浏览器，App 内置 Python。

## 每天使用

1. 打开 App。在本地 Workspace 编辑项目，原文件仍在原目录。
2. NAS 未挂载时点「连接 NAS」，由 Finder 输入账号密码；App 不保存密码。
3. 点「更新 NEXUS」显式扫描两端，并发布两端 08_Indexes 看板。启动只读 NAS 缓存，缓存不代表实时文件状态。
4. 在左右对比中选择单边文件，手动上传或下载。普通复制禁止覆盖；冲突文件只有确认覆盖方向后才替换。
5. 在任务中心确认完成或查看错误；没有完成的文件不能视为已同步。

## 连接与设置

顶部设置可修改本地路径、NAS 挂载路径、SMB 地址和 QuickConnect ID。
Workspace 菜单可重新输入 QuickConnect ID 并打开群晖网页。QuickConnect 不等于 Finder/SMB 挂载。
远程挂载需要已配置的 VPN/ZeroTier 可达地址；本次未安装 VPN、未修改 NAS 权限。

## 日志与安全

- 手动传输后向 NAS 当日日记追加摘要，再将 NAS 日记拉回本地。
- 本地日记有差异时先保留同目录的 *.local-before-nas-*.md，再原子更新正文；需人工检查这些副本中的独有内容。
- 未启用自动同步、自动删除、开机自启或备份计划。同步不是备份。
- 某些群晖 SMB 不支持原子禁止覆盖重命名：兼容模式以排他新建目标写入，同名文件绝不替换；目标在写入阶段可能可见，必须等任务显示完成后再使用。
- 任务持久化保留最近记录。中断后已完成文件保留，未完成文件重新传输；本版不宣称字节级断点续传。
- 多台设备同时写同一日记的跨客户端锁尚未验证，建议错开操作。
- 关闭窗口不停止传输，Dock 点击可重新显示。退出或修改设置时会检查活动任务。
- 菜单可打开浏览器副本、说明和运行日志。
- 「Workspace → 高级工具」保留原控制中心的快照、全文搜索、恢复等工具；它使用升级后的同一套后端。不要在两个窗口同时发起传输或修改路径。

回退须先退出 App，再恢复旧 App 和程序目录；不要覆盖或回滚用户 Workspace。
