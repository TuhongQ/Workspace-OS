# Workspace OS 2.0.6 · Mac 正式构建 206.2

## 安装

适用 Apple Silicon（M 系列）Mac，要求 macOS 13 或更高。Intel Mac 不适用。
打开 DMG，将 Workspace OS.app 拖入 Applications。升级前退出旧 App 和高级工具，
把旧 App 复制到备份目录再替换。无需安装 Python。

程序不会初始化、覆盖或同步您的工作文件。默认本地目录为 ~/Workspace；
在 App 设置中选择已有本地工作区和 NAS 挂载目录。
如尚无本地工作区，先在 Finder 创建，再在设置中选择；不要直接选择整个用户目录。

此包采用本机临时签名，尚未获得 Developer ID 签名及 Apple 公证。
另一台 Mac 的 Gatekeeper 可能要求人工确认来源；请遵循 macOS 的安全提示，
不要关闭系统安全保护。安装包未包含密码、登录会话或用户工作区。

## 使用

双击 App → 连接 NAS → 更新 NEXUS → 对比并手动选择上传/下载。
普通复制不覆盖；覆盖功能需要明确确认方向。同步不是备份。
QuickConnect 只打开群晖网页，不提供 SMB 挂载。
高级工具从 Workspace 菜单进入；不要同时在两个窗口发起传输。
