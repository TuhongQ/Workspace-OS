# Obsidian 使用指南

## 定位

Obsidian 是 Workspace OS 2.0 的知识与项目索引层，不是大型文件仓库。

- Obsidian：笔记、待办、会议、决策、项目主页、知识沉淀。
- Workspace：代码、视频、图片、合同、安装包和其他真实文件。
- NEXUS：查找文件所在位置，并查看本指南。

## Windows 首次打开

1. 启动 Obsidian。
2. 选择“Open folder as vault / 打开文件夹作为仓库”。
3. 选择 `D:\Workspace\02_Knowledge\ObsidianVault`。
4. 打开根目录的 `START-HERE.md`。

Vault 已预配置：

- 新笔记默认进入 `00_Inbox`。
- 每日笔记进入 `01_Daily`。
- 每日笔记模板为 `09_Templates/Daily-Note.md`。
- 模板目录为 `09_Templates`。
- 小型笔记附件进入 `06_Assets`。

## 日常工作流

1. 捕捉：想法、链接和临时信息进入 `00_Inbox`。
2. 计划：每天打开 Daily Note，写今日重点和下一步。
3. 执行：项目主页记录目标、任务、决定与真实文件路径。
4. 沉淀：可复用知识整理进 `03_Knowledge`。
5. 复盘：每周清空 Inbox，完成内容进入 `99_Archive`。
