# 逐步搭建

在“快捷指令”中新建并启用共享表单。依次添加“接收共享输入”“获取文件详细信息”“从菜单中选择类型”“询问输入（项目名）”“格式化日期”“设定名称”“保存文件”“文本”“追加到文件”。保存路径由类型映射到变量表子目录；保存前用“获取文件”检查同名，存在时加 `HHmmss`。日志字段建议为 timestamp、device、original_name、saved_path、size、project。

视频快捷指令在文件超过阈值时显示确认并建议 Wi‑Fi；取消时保持原文件不变。项目笔记使用 Markdown 文本模板而非富文本，保证 Obsidian 和普通编辑器均可读。完成后分别用小文件、中文名、空格名和同名文件测试。
