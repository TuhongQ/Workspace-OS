Obsidian 知识库

Obsidian 用来写笔记、整理知识和记录项目决策；视频、代码和大型文件仍放在 Workspace 项目目录中。

Windows 已准备好：Obsidian 已安装，知识库位于 D:\Workspace\02_Knowledge\ObsidianVault，NAS 副本位于 W:\02_Knowledge\ObsidianVault。

第一次打开（只需做一次）

  1. 打开 Obsidian。
  2. 在欢迎页选择 Open folder as vault / 打开文件夹作为仓库。
  3. 选择 D:\Workspace\02_Knowledge\ObsidianVault，然后点击“打开”。
  4. 打开左侧最上方的 START-HERE（从这里开始），即可看到同一套说明。

以后每天怎么用

  1. 随手记录先放 00_Inbox（收件箱）。
  2. 每天打开 01_Daily（每日记录），写今日重点、过程记录和明日第一步。
  3. 每个工作或生活项目在 02_Projects（项目笔记） 建一张项目主页，只记录目标、进度、决策和真实文件路径。
  4. 可长期复用的经验整理到 03_Knowledge（知识沉淀）；AI 提示词放 04_AI；会议记录放 05_Meetings。

两个实际例子

  • 生活视频：原片和成品仍放 D:\Workspace\01_Projects\Personal\Active\视频项目名；在 Obsidian 建同名笔记，记录选题、脚本、剪辑清单和发布链接。

同步规则

目前不是自动同步：优先打开电脑上的本地知识库，速度更快。完成重要修改后，把整个 ObsidianVault 复制到 NAS。不要同时编辑电脑和 NAS 两个副本；Mac 自动同步将在 Mac 安装阶段单独配置。

如何让 Codex 自动记录

  • 默认自动：在 Workspace OS 项目中，Codex 完成安装、配置、功能改动、自动化或故障修复后，会把摘要写入当天的 Daily Note。
  • 强制记录：对 Codex 说“记录到 Obsidian”“写入知识库”“更新工作日志”，或输入 $obsidian-worklog。
  • 本次跳过：对 Codex 说“这次不要记录”。
  • 记录位置：ObsidianVault/01_Daily/YYYY-MM-DD.md，内容包括操作、技能点、工具新功能、改动文件、验证结果和下一步。

Workspace 使用说明

面向日常工作的简单流程：电脑负责速度，NAS 负责集中保存，看板负责查找位置。

每天怎么用

  1. 新收到、还没整理的文件先放进 D:\Workspace\00_Inbox。
  2. 工作项目放进 01_Projects/Work/Active，生活项目放进 01_Projects/Personal/Active。
  3. 需要找文件时打开本看板，输入文件名、项目名或扩展名，再按位置或类型筛选。
  4. 看板显示“仅电脑”时，文件尚未复制到 NAS；显示“仅 NAS”时，需要从 NAS 打开或复制到电脑。
  5. 显示“版本冲突”时不要直接覆盖，先比较电脑与 NAS 两个版本。
  6. 完成的项目确认无误后移到各自的 Completed，长期不再修改时再归档。

工作与生活示例

  • 生活视频：01_Projects/Personal/Active/视频项目名，原片放 footage，成品放 release。
  • 小米代码：01_Projects/Work/Active/Xiaomi_项目名，源码放 src，发布版本放 release。
重要：本看板现在可以作为本地电脑与 NAS 的文件对比工具使用。普通同步只补齐缺失文件，不会覆盖同名文件；覆盖模式只处理你勾选的文件或文件夹，并且需要二次点击确认。

如何刷新看板与同步差异

Windows 在控制中心点击 打开网页版。程序会重新比较文件和容量，并开启仅本机可访问的后台同步服务；在“文件位置”可勾选单个文件，在“左右对比”可以像文件对比软件一样查看电脑与 NAS 两侧状态，在“目录地图”可勾选整个文件夹。选择 同步到 NAS 或 下载到电脑 时，只复制目标侧缺失的文件；选择 覆盖 NAS 或 覆盖电脑 时，会用源侧文件替换目标侧同名文件，页面会显示百分比进度。直接打开 NAS 上的 HTML 仍可浏览，但不提供同步按钮。

安装与连接说明

当前 Windows 主机已经安装完成；以下步骤用于重新连接或增加一台 Mac。

Windows 当前配置

  • 电脑工作区：D:\Workspace
  • NAS 主工作区：在控制中心点击 NAS 设置 后填写，例如 \\服务器地址\Workspace；也可填写已映射盘符 W:\
  • 刷新入口：桌面快捷方式 Workspace 文件位置
  • NAS 版看板：位于已配置 NAS 的 08_Indexes\file-locations.html

Mac 连接方法

  1. 打开 Finder，按 Command + K。
  2. 输入 smb://<NAS地址>/Workspace，点击“连接”。
  3. 使用群晖用户名和密码登录；可选择记住密码。
  4. 进入 08_Indexes，双击 file-locations.html。
  5. 如浏览器限制直接打开本地网页，可先把该 HTML 拖到浏览器窗口，或在 Finder 中右键选择浏览器打开。

MacBook 安装交接

回到 Mac 后，把 08_Indexes/MacBook-Codex-安装交接.md 中的完整指令粘贴给 MacBook 上的 Codex。跨设备包位于 06_Release/Packages，选择最新且带同名 .sha256 的 WorkspaceOS-Recovery-Portable-2.0.0-*。

提醒：http://<NAS地址>:5000 是群晖管理界面；访问文件应使用上面的 smb:// 地址。

当前安装状态

  • 已完成：Workspace 目录、W: 映射、NEXUS、每日校验快照、GFS 保留、健康检查、全文搜索、关系图、每周审计，以及网页端勾选式同步/覆盖。

NAS 共享文件夹作用

这些是群晖上的顶层共享文件夹，各自用途不同，不建议混用。

共享文件夹作用日常规则
Workspace主工作区和跨设备文件入口；本看板也保存在这里。Windows 与 Mac 日常访问，文件路径保持统一。
WorkspaceArchive存放已经结束、很少再修改的项目和历史资料。完成并确认后再归档；不要把进行中的唯一副本放这里。
WorkspaceBackup预留给后续加密 restic 异机备份。不作为日常工作目录；启用前需离线保存恢复密钥。
WorkspaceSnapshots预留给阶段性快照、导出包或恢复点。Windows 本地校验快照已启用；NAS 副本仍不能代替异机备份。
WorkspacePrivate预留给个人、证件、财务等敏感资料。你此前选择不收紧权限，因此目前不能视为真正私密；放敏感文件前应单独设置权限。
推荐：日常只把 Workspace 当作入口。其他四个共享文件夹是归档、备份、快照和私密用途的专用区域。
