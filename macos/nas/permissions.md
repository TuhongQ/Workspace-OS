# 权限矩阵

| 角色 | Workspace | Archive | Backup/Snapshots | Private |
|---|---|---|---|---|
| 管理员 | 管理 | 管理 | 管理 | 按需审批 |
| 日常用户 | 读写 | 只读 | 无 | 无 |
| 只读设备 | 只读 | 只读 | 无 | 无 |
| iPhone 上传 | 仅 Inbox/Mobile 写入 | 无 | 无 | 无 |
| 自动备份服务 | 读取源 | 读取 | 仅目标写入 | 按策略 |
| 媒体读取账户 | Assets/Release 只读 | 按需只读 | 无 | 无 |

禁用共享账号；启用 MFA、自动封锁、SMB 签名（设备支持时）和访问日志。服务账号不可用于交互登录。
