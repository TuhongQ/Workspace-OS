# 发布规范

1. 独立版本和标签：android-v0.5.5、macos-v2.0.7、ipad-v1.0.0-preview.1、windows-v2.0.7。历史标签不重新指向其他提交。
2. 新安装包上传 GitHub Releases，不进入源码历史；历史 releases/ APK 保留，兼容已有链接。
3. Release 指向准确源码提交，说明最低系统、架构、功能边界、签名/公证状态、测试与未验证项目。
4. 附 SHA-256，上传后核对远端大小及摘要；预览版标为 prerelease，不覆盖其他平台的 Latest。
5. 检查凭据与个人信息，排除运行配置、个人日志、NAS数据、签名私钥和构建缓存。
6. 先 Draft，上传核验后公开。正式发布由人工确认，不自动覆盖旧资产。

自动构建后续按平台接入；本次不启用未经验证的流水线。首页平台下载表是统一入口。
